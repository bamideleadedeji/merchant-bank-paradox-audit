# merchant-bank-paradox-audit
Forensic 30-year audit of global fiscal space (1995-2024) using 798 observations. This Python-based research introduces the Merchant Bank Paradox, identifying a 3-year causal lag in growth decay and a 75.86% debt-trap persistence. Includes PCA-optimized DVI modeling, Markov Chain transitions, and Labor Precariousness Index (LPI) correlations.
